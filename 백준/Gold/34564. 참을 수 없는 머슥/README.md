### 문제 설명

<p>머슥은 문자열을 가지고 노는 것을 매우 좋아한다. 그는 먼저 네 개의 음이 아닌 정수 $a_1,a_2,b_1,b_2$가 주어졌을 때, 다음 조건을 만족하는 <strong>이진 문자열 </strong>$A,B$를 만든다.</p>

<ul>
<li>$A$의 길이는 $a_1+a_2$이다. 단, $A$는 빈 문자열일 수 없다.</li>
<li>$B$의 길이는 $b_1+b_2$이다. 단, $B$는 빈 문자열일 수 없다.</li>
<li>$A$와 $B$를 이어 붙였을 때, 이어 붙인 문자열에서 $\tt{0}$은 정확히 $K$개 존재하여야 한다.</li>
</ul>

<p>이후 머슥은 다음 두 가지 행동을 수행한다. 어떤 문자를 <strong>뒤집는다</strong>는 것은 해당 문자가 $\tt{0}$인 경우 $\tt{1}$로, $\tt{1}$인 경우 $\tt{0}$으로 바꾸는 것을 의미한다.</p>

<ul>
<li>이진 문자열 $A$에서 서로 다른 위치의 문자 $a_2$개를 선택하여 뒤집고, 나머지 $a_1$개의 문자는 그대로 둔다.</li>
<li>이진 문자열 $B$에서 서로 다른 위치의 문자 $b_2$개를 선택하여 뒤집고, 나머지 $b_1$개의 문자는 그대로 둔다.</li>
</ul>

<p>하지만 머슥은 뒤집는 방법 중 다음 조건을 만족하지 않는 방법이 존재한다면 화를 낸다.</p>

<ul>
<li>문자열을 뒤집은 후 문자열 $A$에 있는 $\tt{0}$의 개수와 문자열 $B$에 있는 $\tt{0}$의 개수가 같아야 한다.</li>
</ul>

<p>모그는 $a_1+a_2+b_1+b_2=N$을 만족하는 네 개의 음이 아닌 정수를 머슥에게 줄 것이다. 다만 머슥이 화를 내면 달래기가 매우 번거롭기 때문에, 모그가 선택한 네 정수로 머슥이 어떤 문자열을 만들더라도 머슥이 화를 내지 않도록 해야 한다. 할 일이 많았던 모그를 대신해 $a_1,a_2,b_1,b_2$를 찾아주자. 이 때 수열 $(a_1,a_2,b_1,b_2)$는 <strong>사전순으로 최소</strong>여야 한다. 만약 가능한 답이 없다면 <code><span style="color:#e74c3c;">-1</span></code>을 출력한다.</p>

### 입력 

 <p>첫째 줄에 정수 $N, K$가 공백으로 구분되어 주어진다. $(2\le N\le 10^{18}; 0<K<N)$</p>

### 출력 

 <p>첫째 줄에 모그가 머슥에게 줄 네 개의 음이 아닌 정수 $a_1, a_2, b_1, b_2$를 공백으로 구분하여 출력한다.</p>

<p>만약 가능한 답이 없다면 <code><span style="color:#e74c3c;">-1</span></code>을 출력한다.</p>
